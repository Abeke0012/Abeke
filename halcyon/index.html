03 / Anatomy

Nothing on HX-07 is decorative. Every seam that glows is a cooling channel, every plate that moves carries load, and the suit was designed from the core outward.

B — Core

Six cells in a ring. If one fails the other five carry the suit home.

C — Pauldrons

Layered pauldrons

Three sliding plates per shoulder, free to lag the torso so the arms keep full reach.
