# Abeke

Лендинг «SELF — Build It Your Self» — бургерная с 3D-конструктором бургера (Three.js/WebGL): собери булочку, котлету, соусы и начинки слой за слоем и увидь итоговый бургер и цену в реальном времени.

## Запуск

Статический сайт, зависимостей нет. Открыть `index.html` напрямую или локально:

```
python3 -m http.server 8000
```

и перейти на http://localhost:8000
