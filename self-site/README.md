# SELF — Burgers Made Bold

Лендинг бургерной SELF: Next.js 16, React 19, TypeScript, Tailwind CSS 4, Framer Motion, React Three Fiber.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## Как устроена главная анимация

Hero — это сцена Three.js, привязанная к прокрутке. Секция `#top` высотой 620vh (440vh на телефоне) держит 3D-сцену закреплённой, а прогресс прокрутки 0…1 (со сглаживанием `useSpring` и Lenis) проигрывает рекламный ролик:

| Прогресс | Что происходит |
|---|---|
| загрузка | бургер появляется, камера подлетает, бургер реагирует на курсор |
| 0.06–0.30 | слои по очереди разлетаются вверх и зависают |
| 0.36–0.50 | слои падают обратно, бургер собирается |
| 0.44–0.64 | снизу выезжает чёрная коробка SELF, бургер по дуге ложится в неё рядом с фри и соусом |
| 0.62–0.80 | камера облетает открытую коробку |
| 0.80–0.90 | крышка закрывается |
| 0.90–1.00 | логотип SELF и кнопка «Заказать» |

Все тайминги и путь камеры — в `components/hero/timeline.ts`.

Бургер, коробка, фри и соус построены процедурно (`burgerGeometry.ts`, `SelfBox.tsx`, текстуры рисуются на canvas в `textures.ts`), поэтому внешние 3D-модели не нужны. Если появится настоящая GLB-модель бургера, её можно подставить в `Burger.tsx`, сохранив интерфейс `explode`.

На телефонах, touch-устройствах и при `prefers-reduced-motion` включается облегчённый режим: меньше полигонов, без отражений пола и пост-обработки (глубина резкости, bloom), камера отъезжает, чтобы всё помещалось в вертикальный экран.

## Меню и конструктор

Все позиции, граммовки, цены, комбо, адрес и режим работы взяты из меню SELF (PDF) и лежат в `lib/menu.ts` и `lib/site.ts`. Цены меняются там — конструктор, комбо, меню и тексты разделов пересчитываются сами.

Конструктор (`components/sections/Builder.tsx`) повторяет правила меню: одна булочка, от 1 до 4 котлет (можно разных), любые ингредиенты, до 3 соусов, гарнир и напиток. Итог считается сразу, а 3D-превью собирается из тех же слоёв. Кнопка «Изменить под себя» у готового комбо загружает его в конструктор. Как выглядит каждый ингредиент в 3D, задано в `components/hero/looks.ts`.

## Заказ через WhatsApp

Гость собирает в корзину сколько угодно бургеров (свои и готовые комбо, у каждого своё количество), добавляет гарниры и напитки, выбирает доставку или самовывоз (−10%). Кнопка «Отправить в WhatsApp» открывает чат с номером из `WHATSAPP_NUMBER` в `lib/site.ts` и готовым текстом заказа с итогом. Корзина сохраняется в браузере гостя. Логика заказа и текст сообщения — в `lib/cart.ts`, интерфейс — в `components/cart/`.


## Статическая копия

`STATIC_EXPORT=1 npx next build --webpack` собирает сайт в папку `out/`, которую можно выложить на любой статический хостинг.
